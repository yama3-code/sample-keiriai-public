# 作業マニュアル：旅費仕訳伝票変換

（所管：経理部／最終改定 2025年10月1日）

## 目的
経費精算システムで承認された旅費の明細を、経費精算規程に照らしてチェックしたうえで、会計ソフトに取り込む仕訳伝票に変換する。部門長の承認後でも、経理部で規程との整合を必ず確認する。

## 使うデータ
- **旅費精算明細**（travel-expenses.csv）
- **仮払一覧**（advances.csv）：未精算の仮払金
- **経費精算規程・勘定科目表・部門マスタ**（共通データ）

## 手順

### 手順1：入力データの確認
1. 必須項目（申請No・申請日・社員番号・部門・利用日・区分・金額・支払方法）が埋まっているか確認する。
2. 部門が部門マスタにあるか確認する。
3. 支払方法が「仮払」の明細は、仮払Noが仮払一覧にあるか確認する。

### 手順2：規程チェック（明細ごと）
次の観点で、経費精算規程に違反する疑いがないか確認する。

| 区分 | 確認すること | 根拠 |
| --- | --- | --- |
| 共通 | 申請日が、利用日の翌月10日を過ぎていないか | 規程第4条第1項 |
| 共通 | 申請日が、利用日から3か月を過ぎていないか | 規程第4条第2項 |
| 新幹線 | 一般従業員がグリーン車を利用していないか | 規程第10条第2項 |
| 宿泊 | 1泊あたりの金額が、役職・地域ごとの上限以内か | 規程第10条第4項 |
| 日当 | 出張の定義（片道100km以上）に当たるか。金額が役職・日帰り/宿泊の区分どおりか | 規程第9条・第11条 |
| タクシー | 利用理由が規程の①〜④に当たるか。深夜帰宅（③）は乗車時刻が22時〜翌5時か、10,000円以内か | 規程第12条 |

- 東京本社から片道100km以上：大阪市・名古屋市・福岡市・仙台市・札幌市など。100km未満：横浜市・東京都内など。
- 宿泊が複数泊の場合は、金額 ÷ 泊数 で1泊あたりを計算する。

### 手順3：チェック結果による扱い
- **違反の疑いなし**：仕訳を作成する。
- **翌月10日の期限超過のみ（3か月以内）**：仕訳を作成し、要確認事項に「期限超過」と記載する。
- **それ以外の違反の疑い**：その明細は仕訳を作成せず「保留」とし、要確認事項に理由と根拠条文を記載する。同じ申請の他の明細は通常どおり処理する。
- **3か月超過**：その申請のすべての明細を保留とする。
- 規程に書かれていない判断が必要なもの（例：上限超過の理由が書かれている）も、勝手に認めず保留とする。

### 手順4：仕訳の作成
1. 科目は、すべて借方「旅費交通費（6140）」とする。部門は申請者の部門。
2. 貸方は支払方法で決める。
   - 立替 → 未払金（2120）。摘要の先頭に社員番号を入れる（25日の精算振込と照合するため）。
   - 法人カード → 未払金（2120）。摘要の先頭に「法人カード」と入れる。
   - 仮払 → 仮払金（1250）。
3. 1明細＝1行とし、借方・貸方とも同じ金額にする。貸方の部門は空欄とする。
4. 日付は申請日、伝票番号は「TR-申請No」（例：TR-T-1201）。
5. 摘要は「E1023 大阪出張 新幹線 往復」のように、社員番号（または法人カード）・行き先・区分・内容の要点を入れる。

### 手順5：仮払金の精算
1. 仮払の明細がある申請について、仮払額と、仮払で精算した明細の合計（保留を除く）を比べる。
2. 仮払額の方が多い場合：差額は申請日に従業員から普通預金へ返金されたものとして、借方 普通預金（1120）／貸方 仮払金（1250）の仕訳を同じ伝票番号で作成する。摘要は「K-0031 仮払金 残額返金」。
3. 仮払額の方が少ない場合：差額を借方 旅費交通費／貸方 未払金で追加し、要確認事項に記載する。
4. 精算の明細がない仮払金（今回の明細に出てこないもの）は、作業ログに「未精算のまま」と記録する。

### 手順6：検証
1. 伝票ごと・全体で、借方合計と貸方合計が一致するか確認する。
2. 作業ログに、申請ごとの処理結果（仕訳作成／一部保留／全部保留）と金額を記録する。
