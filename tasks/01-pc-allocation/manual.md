# 作業マニュアル：PC経費配賦仕訳変換

（所管：経理部／最終改定 2025年10月1日）

## 目的
PC関連費用は、毎月いったん管理部（部門コード110）で全額を計上している。月次決算で、これを各部門の利用実態に応じて配賦（負担を振り分けること）し、部門別の損益を正しくする。

## 使うデータ
- **PC関連費用明細**（pc-costs.csv）：管理部で計上した当月のPC関連費用
- **部門別PC台数**（pc-counts.csv）：月末時点の部門別PC台数
- **部門マスタ**（共通データ）：部門別の人数

## 手順

### 手順1：入力データの確認
1. 費用明細の各行について、対象月・科目コード・金額・配賦区分がそろっているか確認する。
2. 科目コードが勘定科目表にあるか確認する。
3. 部門別PC台数の部門が部門マスタとすべて一致しているか、台数が0以下の部門がないか確認する。
4. 不備がある行は配賦せず、要確認事項に記載する（例：配賦区分が空欄）。

### 手順2：配賦基準の決定
費用明細の「配賦区分」に従う。
- **台数基準**：部門別PC台数の比率で配賦する。
- **人数基準**：部門マスタの人数の比率で配賦する。
- **配賦対象外**：配賦しない。仕訳も作らず、作業ログに「対象外」と記録する。
- 上記以外・空欄：配賦せず、要確認事項に記載する。

### 手順3：配賦額の計算
1. 各部門の配賦額 ＝ 費用の金額 × その部門の基準値 ÷ 基準値の合計
2. 円未満は切り捨てる。
3. 切り捨てにより配賦額の合計が元の金額に足りない場合、その差額は**基準値が最も大きい部門**に加算する。
4. 配賦額の合計が元の金額と一致することを必ず確認する。

### 手順4：仕訳の作成
1. 管理部の負担分は管理部に残るため、仕訳は作らない。管理部以外の各部門について、次の振替仕訳を作る。
   - 借方：元の科目（配賦先の部門）／貸方：元の科目（管理部）
   - 例：借方 賃借料（開発部）1,047,558円 ／ 貸方 賃借料（管理部）1,047,558円
2. 日付は対象月の末日とする。
3. 伝票番号は、費用明細1行につき1つとし「PC-対象年月-明細No（2桁）」とする（例：PC-202512-01）。同じ明細の部門別の行は同じ伝票番号にする。
4. 摘要は「12月分 PCリース料 配賦（台数 182/344台）」のように、対象月・費目・基準・基準値を入れる。

### 手順5：検証
1. 費目ごとに、配賦した合計（管理部の負担分を含む）が元の金額と一致するか確認する。
2. 全仕訳の借方合計と貸方合計が一致するか確認する。
3. 作業ログに、費目ごとの配賦結果（部門別の金額）を記録する。

## 注意事項
- 配賦基準の変更や、新しい費目の追加は経理部長の承認が必要。明細に見慣れない費目がある場合は要確認とする。
- 前月の配賦結果との比較は行わない（別の作業で行う）。
